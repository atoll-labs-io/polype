## The pivot
**The profile records the commands next-forge really has, even where the template asks for more: `Test: bun run test` takes no path and `Typecheck` is `—`.** The template (`method/templates/profile.md:22`) says a `Test` must accept paths, but no root command of next-forge does (`NF:package.json:23`, `NF:turbo.json`), and inventing one (`turbo test -- <filter>`, `bun run --filter`) would put an unverified command into every project's `AGENTS.local.md`. The gap is written in `## Known traps` and under the fence instead. How it could be wrong:
- A reviewer reads the template's sentence as a hard rule — compare with the story's "décrire le dépôt réel, pas ce qu'on en suppose" (`docs/stories.md:628`): grounding wins, the deviation is stated, not hidden.
- The grounded test turns every run into a network call and may skip offline — compare with `tests/overlap.test.sh:12-15`, the accepted precedent; `NEXT_FORGE_SRC` lets a run be offline and real.
- The path extraction misses a path cited without backticks — the profile writes every repository path in backticks; the `at least 15` floor catches an extraction that finds nothing.
