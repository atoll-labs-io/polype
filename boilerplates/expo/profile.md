## Commands

```
Install:           npm install
Test:              npx jest
Typecheck:         npx tsc --noEmit
E2E:               —
Build:             —
Dev:               npm run web
```

None of these was run here. `Test` needs `jest-expo` and `jest` installed as the Expo guide "Unit Testing with Jest", named by the README, describes; it accepts paths to test files and ends. Until a first story installs them, `npx jest` fails: the template ships no test runner. `npm test` would be the guide's `jest --watchAll`, which never returns, so it is not used. `Typecheck` assumes the `typescript` dependency provides `tsc`. `Build` is `—` because the template has no build script.

`Dev` runs `expo start --web` and serves the web render of the app on `http://localhost:8081` by default. Without a TTY, or with `CI` set, it prints `Waiting on <url>`, which is the address to read; it also tries to open a desktop browser.

## Code map

- `src/app/` — file-based routes of Expo Router: `_layout.tsx`, `index.tsx`, `explore.tsx`.
- `src/components/` — shared components; `ui/` holds `collapsible.tsx`.
- `src/constants/theme.ts` — colour and spacing tokens.
- `src/hooks/` — theme and colour-scheme hooks.
- `src/global.css` — global styles, used by the web render.
- `assets/` — images and the app icon.
- `scripts/reset-project.js` — moves the starter code out of the way.
- `app.json` — Expo configuration: portrait orientation, static web output, typed routes and React Compiler on.
- `package.json` — scripts `start`, `reset-project`, `android`, `ios`, `web` and `lint`; entry `expo-router/entry`.
- `tsconfig.json` — strict TypeScript, the alias `@/*` for `src/*`.

## Ownership granularity

A story owns a new `src/app/<route>.tsx` plus its own components under `src/components/`. Shared: `src/app/_layout.tsx`, the tab list in `src/components/app-tabs.tsx` and `src/components/app-tabs.web.tsx`, `src/constants/theme.ts`, `app.json` and `package.json`.

## Where each rule lives

- Routes and screens: `src/app/`, one file per route.
- Validation, access, tenant filter and data: no such layer ships; a story adds them beside the route it protects.

## Known traps

- Some components have a `.web.tsx` twin: `src/components/app-tabs.tsx` uses native tabs while `src/components/app-tabs.web.tsx` uses a web `Tabs`, so the web render the QA driver sees does not show the native tab bar.
- `expo-env.d.ts` and `.expo/types` are generated by Expo and ignored; `tsconfig.json` includes them, so a typecheck before a first `expo start` may miss typed routes.
- `/ios` and `/android` are generated by prebuild and ignored by git.
- `npm run reset-project` moves the starter code to `example/`.
- The template folder tracks a stray `.tgz` of an older version; it is not part of a generated project.
- Licence: `0BSD` for the template, MIT for the repository around it.
- `npm test` is the guide's watch mode; use `npx jest`.
- `npm run lint` runs `expo lint`, which sets ESLint up on its first run.
